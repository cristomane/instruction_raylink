# RayLink Instruction

Веб-инструкция по подключению к сервису **RayLink**.

## О проекте

**RayLink** — это VPN-сервис для безопасного и стабильного доступа к интернету.  
Этот репозиторий содержит сайт-инструкцию для пользователей RayLink: как установить клиент, импортировать конфигурацию и подключиться на разных платформах.

## Что есть на сайте

- пошаговые инструкции для `iOS`, `Android`, `Windows` и `macOS`
- FAQ с ответами на частые вопросы
- ссылки на поддержку и новости проекта

## Технологии

- `React`
- `TypeScript`
- `Vite`
- `Tailwind CSS`
- `GSAP`

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Готовый билд будет в папке `dist/`.
